# Networking Experiments

Study DNS, TCP, TLS, routing, latency, throughput, packet loss, reverse proxies, and service reachability.

Useful public-safe tools include `dig`, `curl`, `ping`, `ss`, `traceroute` or `tracepath`, and `openssl s_client`.

Record the test location, destination, protocol, packet size or request size where relevant, and time of measurement.

Do not publish private network maps or customer infrastructure details.
