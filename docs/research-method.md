# Research Method

Infrastructure research should be reproducible and evidence-driven.

## Workflow

`Question → Hypothesis → Experiment → Measure → Compare → Analyze → Record → Reproduce`

## Experiment Record

Record the objective, environment, variables, procedure, measurements, result, limitations, and next experiment.

## Control Variables

Change one important variable at a time where practical. Keep software versions, workload size, concurrency, and measurement method documented.

## Evidence

Separate measured facts from interpretation. If a result is uncertain, record the uncertainty rather than forcing a conclusion.

## Reproduction

A useful research note should give another engineer enough information to repeat the experiment using a safe, non-production environment.
