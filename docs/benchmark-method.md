# Benchmark Method

Benchmarking infrastructure requires context as well as numbers.

## Record

- CPU and available cores
- RAM and swap
- storage and filesystem
- operating system and kernel
- runtime/software versions
- network location and protocol
- workload and concurrency
- warm-up behavior
- repetitions
- measurement tool
- timestamp

## Compare

Use the same workload and methodology when comparing configurations. Report median and variation when enough samples exist.

## Avoid

Do not treat one run as a universal performance claim. Do not compare results collected under materially different workloads without explaining the difference.
